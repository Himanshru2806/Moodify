# Track Catalogue

The current API uses an in-code demo catalogue only. The frontend opens a YouTube Music search for each title and
artist; it does not yet resolve or verify an exact platform track or play audio inside Moodify.

When replacing it, record:

- Track source and licensing notes.
- Fields included in the catalogue.
- Any manual curation decisions.
- Whether playable links are previews, external links, or locally licensed files.
- The platform track ID or canonical URL when exact track resolution is added.

Do not commit copyrighted audio files or scraped protected metadata.
